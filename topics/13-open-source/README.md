> How I contribute to open source — 7 merged PRs.
> **YouTube playlist:** Open Source Contribution · [youtube.com/@aiwithrav](https://www.youtube.com/@aiwithrav)

Part of the **AI with Rav** learning universe. Each video = a branded PDF built from the shared factory template.

## How this folder works
- Each video's content lives in `days/dayNN.md` (title + content only).
- Run the factory to build the branded PDF:
  ```
  python3 ../../build_master_pdf.py topics/13-open-source/days/dayNN.md
  ```
- The cover (logo + photo + "Open Source Contribution" + DAY badge) is automatic — identical style across all topics.

- Diagrams for each video are generated by `images/_generate_dayN_images.py` (matplotlib, dark theme).

### Arc across the series
Day 1 introduces the method (use the library, find the unclaimed bug, ship a test).
Days 2–3 are a pair: one fix, the maintainer finding the case it missed, and the scope
conversation that turned it into two PRs. Days 4–5 cover contributing tests with no bug
attached. Days 6–7 are honest about documentation PRs — 35 opened, 2 merged — and close
the series on what the seven are actually worth in an interview.

### Rebuilding
```
python3.12 topics/13-open-source/images/_generate_day1_images.py
python3.12 topics/13-open-source/images/_generate_day2to7_images.py
for d in 01 02 03 04 05 06 07; do
  python3.12 build_master_pdf.py topics/13-open-source/days/day$d.md
done
```
Note: use `python3.12` — it is the interpreter with matplotlib, reportlab and Pillow installed.
