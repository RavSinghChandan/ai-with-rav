title: The Python bug that hides for months
---

@hook|This Python function **breaks silently**

@beat|`def add(item, basket=[])` — the list is built **once**, when Python reads the def.

@beat|Every call that does not pass a basket shares that **same list**. Forever.

@beat|Call it twice and the first item is still there.

@takeaway|Never put a list, dict or set in a default argument. Use None.
