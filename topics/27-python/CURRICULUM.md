# 🐍 Python for AI Engineers — 30-Day Curriculum (STATIC — never deviate)

> LOCKED agenda. The FOUNDATION module — Stage 1 of the "Developer → AI Engineer" roadmap.
> Taught SCRATCH-FIRST (a true beginner in 2031 can follow) + quick one-line language bridges
> ("if you know Java, a list is like an ArrayList") so working developers move fast too.
> Focus on TIMELESS fundamentals — 6-7 year value. Days 21-30 add the AI/data essentials.
> Same rules: story-first, 5 diagrams/day, 6th-grade English, real code explained simply.

## Part 1 — Python Fundamentals from Scratch (Days 1-8)
| Day | Title | Covers | Story angle |
|---|---|---|---|
| 1 | Why Python for AI? + Your First Program | What Python is, why AI loves it, print/run | A simple, plain-English language |
| 2 | Variables & Data Types | int, float, str, bool — storing values | Labelled boxes holding things |
| 3 | Strings | Text, slicing, f-strings, methods | Working with words like clay |
| 4 | Numbers & Math | Operators, int vs float, // % ** | The calculator built in |
| 5 | Input, Output & Comments | Talking to the user, readable code | A two-way conversation |
| 6 | Booleans & Comparisons | True/False, ==, and/or/not | Yes/no questions |
| 7 | If / Elif / Else | Making decisions | The road that forks |
| 8 | Type Conversion & Errors | Casting, common beginner errors | Translating between box types |
