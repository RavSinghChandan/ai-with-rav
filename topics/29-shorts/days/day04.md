@callout|yellow|In One Line: Every AI job posting asks for Python. None of them are hiring you for Python.

@h2|The honest picture
Python is the **keyboard**, not the job. Saying you know Python is like a
carpenter saying he owns a hammer.

Companies hire for three layers. Most developers stop at the first.

@image|images/img04-three-layers.png|Everyone has layer 1. Layer 3 is where the job offers are.

@h2|Layer 1 — the tools
Python, an API call, a notebook that runs. Genuinely necessary. Also what
everyone applying has.

@h2|Layer 2 — the judgement
Which model, and why. When retrieval beats fine-tuning. What your system does
when the model returns nonsense.

This is where the interview actually happens.

@h2|Layer 3 — the evidence
Something running that someone other than you has used. A repo with a README
that explains the trade-offs you chose and what you would do differently.

@callout|blue|One deployed project you can defend in detail beats ten tutorials you followed.

@h2|What to do this month
Pick one real problem. Build the smallest version that works. Deploy it. Write
down honestly what it does badly.

@callout|green|That last document — the honest one — is the strongest thing in an AI portfolio. Almost nobody writes it.
