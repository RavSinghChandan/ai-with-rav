title: Dependency injection in one picture

@hook|You stop writing `new`. Spring **hands you** what you asked for.

@image|images/short01-di.png|You declare the need; the container supplies it

@beat|Your class declares: I need a `UserRepository`.

@beat|Spring finds one, builds it, and passes it in.

@beat|Your class never knows which implementation it got — that is the point.

@takeaway|Testing becomes easy because you can hand it a fake instead.
