title: Dependency injection in 60 seconds
---

@hook|Stop writing **new**. Let Spring hand it over.

@image|images/short01-di.png|You declare the need; the container supplies it

@beat|Your class declares what it needs: a `UserRepository`.

@beat|Spring finds one, builds it, and passes it in.

@beat|Your class never knows which implementation it got. That is the point.

@takeaway|Testing gets easy, because you can hand it a fake instead.
