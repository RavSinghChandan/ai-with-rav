title: Show, don't describe

@hook|One **example** beats three paragraphs of instructions. Every time.

@image|images/short01-fewshot.png|Instructions guess; examples pin it down

@beat|'Write formally' is vague — the model guesses what you mean.

@beat|Give one input and one ideal output, and it matches the pattern.

@beat|Two or three examples pin down tone, length and format together.

@takeaway|When a prompt is not working, add an example before adding more words.
