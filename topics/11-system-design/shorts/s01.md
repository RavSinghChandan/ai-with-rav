title: Cache the expensive thing, not everything
---

@hook|A cache is a bet: **this will be asked again**. Bet wrong and you have added complexity for nothing.

@image|images/short01-cache.png|Slow and repeated is worth caching; nothing else is

@beat|Cache what is **slow to compute** and **often repeated**.

@beat|Never cache what changes per user per second — you pay the cost, never the benefit.

@beat|Every cache needs an answer to: **when does this become wrong?**

@takeaway|If you cannot say when an entry goes stale, you are not ready to cache it.
